About

How this blog is made

{{ site.name }} is AI-assisted. Every post is generated automatically from public sources, and every post links to all of them. {{ site.byline }} set it up, chose the sources and wrote the rules it follows, but does not hand-edit the daily posts.

The daily run

  1. Collect. Early each morning (India time) a scheduled job reads the public feeds listed below: AI lab blogs, arXiv, Hugging Face, tech news sites, Hacker News and new GitHub projects.
  2. Rank. Stories are grouped when several outlets cover the same event, then scored on how recent they are, how many independent outlets covered them and how much attention they got. Anything covered in the last two weeks is skipped, so you never read yesterday's news twice.
  3. Read. For the top stories, the job fetches the linked pages and keeps their text. That text is the only material the writer is allowed to use.
  4. Write. A language model drafts the post in plain language, and must cite a source on every sentence.
  5. Verify. A program then checks every number and every name in every sentence against the text of the source it cites. A second pass has the model re-read each sentence next to its source and flag anything the source doesn't support. Whatever can't be confirmed is deleted, not reworded. Each post links to its own verification log.
  6. Gate. The post is published only if it is the right length, has its three "what happened" bullets and at least three stories, contains no hype words, every source link resolves, every image exists, and it isn't a repeat of a recent post. If the first draft fails, the job tries once more. If that fails too, there is no post that day. A missing day is better than a wrong one.

House rules

  • Facts in the sections, opinion only in "Why it matters", and opinion is labelled speculation.
  • At most one short direct quote per post, copied word for word.
  • Charts and diagrams are drawn by this site from numbers in the sources. No images are copied from anyone.
  • No ads, no cookies, no personal data. One small script from GoatCounter counts visits anonymously (page, referrer, device type; no IP addresses kept, nothing to follow you across sites). The theme choice is stored only in your own browser.

What the checks can't catch

The verifier confirms that each number and name appears in the cited source, and the model pass looks for claims the source doesn't support. Neither can tell you whether the source itself is right, and a sentence can use correct words and still put them together in a misleading way. If you spot an error, the source links are there so you can check it yourself, and corrections are welcome on GitHub.
