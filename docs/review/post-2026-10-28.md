## Unlimited OCR 2 introduces sparse reference sliding window attention
*Architecture*

On 27 October 2026 Baidu released Unlimited OCR 2, a model for image‑to‑text conversion that can parse documents of unlimited length<sup>6</sup>. The release was announced on Hugging Face model cards and accompanied by a new benchmark called MarathonDocBench for ultra‑long document parsing<sup>6</sup>. The model is available through ModelScope, Baidu Cloud and a public demo on Hugging Face Spaces<sup>6</sup>.

Unlimited OCR 2 uses Sparse Reference Sliding Window Attention (SR‑SWA), which reduces the interaction between text and visual tokens to a fixed set of references, such as 512 tokens, regardless of document size<sup>6</sup>. This design keeps per‑step decoding latency and memory use almost constant as the document grows, unlike traditional attention that scales quadratically<sup>6</sup>.

## Brooks’s law in the age of AI agents
*Tools*

The piece asks whether the law still applies when autonomous agents replace human developers<sup>8</sup>.

The author argues that AI agents eliminate some traditional bottlenecks such as onboarding time, stand‑up meetings, and coffee breaks, because an agent can be ready in milliseconds and never needs a break<sup>8</sup>. However, the “Baby Problem” persists: nine agents cannot produce a baby in one month, illustrating that sequential tasks remain sequential<sup>8</sup>. Overhead shifts from people management to agent orchestration, requiring clear definitions of “done,” code review, hallucination detection, and integration of outputs<sup>8</sup>. Throwing nine autonomous agents at a codebase without precise coordination leads them to overwrite each other's work rapidly<sup>8</sup>.

Brooks's law originated from the IBM OS/360 project, where adding staff to a late schedule increased delays, a principle still taught in software engineering<sup>8</sup>. The article suggests updating the law to reflect unclear requirements when using AI agents<sup>8</sup>.
